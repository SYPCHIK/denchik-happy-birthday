# Denchik Happy Birthday

Интерактивный сайт-поздравление с тестом выбора подарка.

## Как менять подарки

Основные варианты лежат в `app.js` в объекте `gifts`. Сейчас выбор подарка сделан как турнирная сетка: квалификация, полуфинал и финал. Для каждого подарка можно заменить:

- `name` — название подарка
- `tag` — короткий режим результата
- `caption` — подпись на финальной карточке
- `reveal` — текст после кнопки `Открыть подарок`
- `image` — картинку из папки `assets`

Раунды турнира лежат ниже в массиве `tournamentRounds`.

## Картинки подарков

Когда будут готовы картинки, положи их в `assets` с такими именами:

- `gift-outfit.png` — друзья тебя круто оденут
- `gift-squad.png` — стрелялка Сквад
- `gift-motor-kit.png` — конструктор для развития моторики
- `gift-business-pen.jpeg` — крутая ручка бизнесмена-миллионера
- `gift-minecraft-rtx.png` — майнкрафт с трассировкой лучей
- `gift-samp-case.png` — кейс-миллионера из SAMP
- `gift-apartment-kit.png` — набор «Сделай квартиру сам»

Пока этих файлов нет, сайт использует временные картинки-заглушки из уже существующих ассетов.

## Звуки хоррор-кнопки

- `horror-music.mp3` — музыка, стартует почти сразу после кнопки `Да, ломаем`
- `horror-scream.mp3` — скример, стартует вместе с первой screamer-фоткой

## Кадры для стартовой анимации

Положи четыре картинки Денчика в папку `assets` с такими именами:

- `denchik-laugh-1.png` — обычное лицо
- `denchik-laugh-2.png` — улыбается
- `denchik-laugh-3.png` — улыбается с открытым ртом
- `denchik-laugh-4.png` — голова чуть ниже

Сайт сам будет переключать их как мини-анимацию смеха.

## Звуки спецэффектов

Файлы `sfx-confetti.ogg`, `sfx-super-effects.ogg` и `sfx-mega-effects.ogg` взяты из Kenney Interface Sounds под лицензией Creative Commons Zero (CC0): https://kenney.nl/assets/interface-sounds
